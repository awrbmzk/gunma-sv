標高での絞り込みは、データに標高を追加すると使えます。

「道路」は道幅どおりの帯で描きます（ふちが黒・中が白）。等高線・記号・地名は最初から消してあります。引いたときは地理院の道が間引かれてしまうので、その範囲だけ OpenStreetMap の道で補っています。

このブラウザにだけ保存されます。キーには Maps JavaScript API の権限と、請求先アカウントの有効化が必要です。保存すると読み込み直します。

この端末の記録

消した道 0 本 ／ 0 km
残り 0 本

地図の中心と拡大率をそのまま引き継いで、Googleマップのサイト（アプリがあればアプリ）が開きます。右下の G ボタンでも同じことができます。

マウスなら、地図の上を右ドラッグでなぞるとその範囲をまとめて消せます（左ドラッグは地図の移動）。指で操作するときは右下の ➰ ボタンを押してからなぞってください。
